The manager and the plan

Orchestrator

(the agent)

  • Coordinates every agent
  • Retries and error handling
  • Round limits, then escalate to a human (for example, three rounds)
  • What to do on failure
  • The overall process logic

Workflows

(the defined flow)

  • An explicit series of steps
  • Defined once, run repeatably
  • GitHub Copilot orchestration features for declaring a flow

The questions the orchestrator answers: how do you handle many agents at once, what happens when one fails, how many times do you retry, how long do two agents go back and forth before a person steps in. Without a limit, a review loop can run forever; the limit is what makes it manageable.
