# How to Successfully Manage Multi-Agent Ensembles

Slides for Miguel Martinez's Tech Futures 2026 talk (Principal AI Solutions Engineer, Microsoft).

**Live deck:** https://miguelmodel.github.io/20261006-multi-agent-ensembles-conference/

## Navigate

- `→` / `Space` / `PgDn` — next reveal step, then next slide
- `←` / `PgUp` — previous step, then previous slide
- `Home` / `End` — first / last slide
- `F` fullscreen · `N` speaker notes · `A` settings (themes, slide list, PDF export)

## Run locally

```bash
npm install
npm run dev
```

Built with Vite and GSAP. Slide 7 chart data: METR, "Task-Completion Time Horizons of Frontier AI Models" (Time Horizon 1.1), metr.org/time-horizons, last updated May 8, 2026.
